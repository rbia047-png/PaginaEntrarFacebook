# 📱 Recriação da Página Inicial do Facebook

Projeto desenvolvido com o objetivo de recriar a página inicial do Facebook, utilizando HTML e CSS. O projeto busca reproduzir a estrutura visual da página de login, incluindo campos de acesso, botões, imagens e organização dos elementos.

Também foram aplicados conceitos de responsividade para adaptar a página a diferentes tamanhos de tela, como computadores, tablets e celulares.

### 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Design Responsivo

### 🎯 Objetivo

Praticar a criação de interfaces web, posicionamento de elementos, estilização com CSS e desenvolvimento de páginas responsivas inspiradas em interfaces reais.
